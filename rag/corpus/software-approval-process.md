# Getting software approved and installed

**Service:** software-center
**Type:** policy
**Applies to:** all staff

## Already-approved software

Open **Software Center** on your corporate device. Anything listed there is
already approved and installs without a ticket. This covers most common
tooling.

If an install in Software Center fails, it is usually one of two things: your
account lacks an entitlement for that application, or an Endpoint Protection
policy is blocking the installer. Raise a ticket with the application name and
the error shown.

## Requesting something new

Raise a request including:

- the application name, vendor, and version
- what you need it for, in one or two sentences
- whether it processes customer or personal data
- whether a licence is already held by another team

## Review path

1. **IT review** — checks for an existing approved alternative. Most requests
   stop here, because one usually exists.
2. **Security review** — required if the application handles customer or
   personal data, or requests broad device permissions.
3. **Licence and budget** — the cost centre owner approves the spend.

Allow **ten working days** end to end. Security review is the slowest step,
and starting it early is the only way to speed this up.

## Personal and unapproved software

Do not install software from outside Software Center on a corporate device,
including free tools and browser extensions. Corporate devices block
unapproved installers, and attempting to bypass that block is a policy
violation rather than a technical problem.
